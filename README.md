# House Price Prediction

This project focuses on predicting house prices using Machine Learning techniques based on various property features such as area, number of bedrooms, bathrooms, parking availability, furnishing status, and other housing attributes.

## Project Objectives

* Perform data loading and exploration
* Clean and preprocess the housing dataset
* Train and evaluate regression models
* Visualize important patterns and relationships in the data
* Identify the factors that influence house prices

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Matplotlib
* Seaborn
* Jupyter Notebook

## Dataset

Dataset Source:
https://www.kaggle.com/datasets/yasserh/housing-prices-dataset

## Visualizations

The project includes visualizations such as:

* House Price Distribution
* Correlation Heatmap
* Actual vs Predicted Prices
* Feature Importance Analysis
